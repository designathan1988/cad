# A aplicação é só para desktop

O cad2 não é para celular. Não testar, não revisar nem projetar para larguras de celular.

**Por quê:** o dono disse em 2026-10-28: "a aplicação não é para mobile, pare de perder tempo com isso".

**Como aplicar:** testes e revisões de interface em larguras de desktop (~1280 e 1920 px; ~880 só quando a regra de larguras pedir). Nada de viewport mobile nem itens de "responsivo para celular" em relatórios.
