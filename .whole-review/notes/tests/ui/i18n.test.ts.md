# tests/ui/i18n.test.ts
Lines: 35
Summary: Tests of stored default names:
- Default names are stored in one form (English) and read in the language of the moment: "Level 2" is shown as "Pavimento 2", "Room 3" as "Cômodo 3", and "Ground floor" as "Térreo".
- A new wall type and a copy are named so that the built-in part is still translated; a user's own name with "(2)" stays as typed.
- The user's own names are never translated.
Because names are recognised by their English pattern, a name the user types that happens to match exactly (for example "Room 3") would also be translated. This is a design choice, not a finding.

## Contracts, state and data flow
- name() matches stored strings against known default patterns, by regular expression or table, and translates them. Anything else is returned as typed.
