## Contracts, state and data flow
- `pt` is typed Record<MessageKey, string>, so every `en` key needs a Portuguese text (tsc checks it); nothing checks that a key is read.
- Language is module state (setLang); messages are looked up at render time.
- Variables are filled by name; a missing one becomes an empty string silently. The {key} messages are filled by app.keyName(actionId) (app.ts): the key as the user set it, the action's name in quotes when it has none.
